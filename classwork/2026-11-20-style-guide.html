My Style Guide

See the assignment

My work

My colors

  • Page background: #171326
  • Text: #FFF4E0
  • Headings: #B69CFF
  • Links: #FFE66D
  • Accent: #FF4F87

My font

My font is "Comic Neue", sans-serif;. I used it on the whole page (it's in my body rule).

Rules I wrote

Rule 1

body {
    background-color: var(--background);
    color: var(--text);
    font-family: 'Comic Neue', sans-serif;
    font-size: 17px;
    line-height: 1.8;
    margin: 0;
    padding: 28px;
}

Sets the page's background, text color, font, size, and spacing.

Rule 2

h1 {
    color: var(--accent);
    font-size: 48px;
    font-weight: 700;
    text-align: center;
    text-shadow: 2px 2px 4px var(--purple);
    transform: rotate(-1deg);
}

Styles the main heading with color, size, bold text, shadow, and slight rotation.

Rule 3

a {
    color: var(--link);
    font-family: 'Space Mono', monospace;
    font-weight: 700;
    text-decoration: none;
    transition: color 0.2s ease;
}

Styles links with color, bold monospace text, and smooth transitions.

My class

a:hover {
    background-color: var(--accent);
    color: var(--background);
    border-radius: 8px;
    padding: 4px 8px;
    text-decoration: underline;
}

I used it on the links. Changes link colors, adds a rounded background, and underlines links when hovered

What I'd change now

I'd use flexbox to organize my content better and make the layout cleaner.
